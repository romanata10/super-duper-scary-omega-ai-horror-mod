# Super Duper Scary Omega Horror

Экспериментальный мод для **Minecraft Java 1.20.1 / Forge 47.2.0**. Это ранний прототип, а не готовая реализация всех задумок.

## Что уже есть

- При размещении пяти кнопок в радиусе четырёх блоков появляется Великая злая кнопка (пока выглядит как зомби). Она расставляет дубовые кнопки; после смерти выпадает ровно 240 кнопок. Пока поблизости уже есть такой моб, ещё один не появляется.
- Иногда рядом с игроками появляются Давид, NULL, Soundpad и Mart: пока это именованные зомби-заглушки, а не полноценные модели. Давид убирает оказавшихся рядом коров и забирает вёдра молока из инвентаря игрока поблизости, оставляя пустые вёдра. Soundpad издаёт случайные звуки и оставляет предмет, который воспроизводит случайный звук по правому клику.
- Если ударить рыбку или что-то поймать на удочку, рыбки поблизости преследуют и кусают игрока.
- Иногда появляется явно обозначенное как шутка сообщение о насосе Василии. При слове «роблокс» или «roblox» в чате игроку показывается **вымышленная** история браузера. Мод не читает реальную историю и не взламывает компьютер.
- Носки в инвентаре дают повышение здоровья и силу; для полного заполнения дополнительного здоровья требуется лечение. В творческом инвентаре есть блок Krita: нажмите по нему красителем, чтобы покрасить весь блок. Несколько блоков можно использовать как пиксели рисунка.

- Обычное ведро молока можно вылить нажатием на блок. В молоке можно плавать; за купание выдаются 64 ведра молока (не чаще раза в игровой день). В Minecraft вёдра молока не складываются в один стак, поэтому лишние выпадут рядом.
- Редко возникает торнадо из облаков, которое затягивает и поднимает живых существ.

- Глаз Iris из творческого инвентаря переносит в мрачное измерение Iris и обратно в точку появления обычного мира. Это пока измерение на основе ландшафта Края, а не точная копия планеты из Gemini Home Entertainment.

## Ещё не реализовано

Полноценная планета Iris, попиксельное рисование на одном блоке Krita, рабочий браузер, самолёт, полноценные уникальные модели и механики монстров. Эти функции не следует считать готовыми.

## Сборка

Установите JDK 17 и Gradle 8.1.1, затем выполните `gradle build`. Готовый JAR будет в `build/libs/`; установите его в папку `mods` клиента и сервера Forge 1.20.1. Для проверки в среде разработки используйте `gradle runClient`. Для первой сборки нужен доступ к репозиториям Forge и Gradle. Gradle Wrapper в проект пока не включён.

Сборка проверяется GitHub Actions. Игровая проверка пока не проводилась; рекомендуется предварительно сделать копию мира.
