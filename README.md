# super-duper-scary-omega-ai-horror-mod

Очень страшный хоррор-мод для Minecraft 1.20.1 (Forge). Скачай `.jar` из [Releases](https://github.com/romanata10/super-duper-scary-omega-ai-horror-mod/releases) и закинь в папку `mods`.

## Что внутри (все 16 фичей)

1. **Планета Iris** — измерение из analog horror в духе Gemini Home Entertainment (`/execute in omega_horror:iris`).
2. **David** — страшный монстр, который крадёт твоих коров и всё твоё молоко.
3. **Ведро молока** — молоко выливается как настоящая жидкость.
4. **Купание в молоке** — если выкупаться в молоке, David подарит тебе стакан молока.
5. **Великая злая кнопка** — поставь 5 кнопок рядом, появится кнопочный монстр, который расставляет кнопки везде; убей его — выпадет **240 кнопок**.
6. В чате иногда пишется: «☠ ТВОЙ ПК ВЗЛОМАН НАСОСОМ ВАСИЛЕЕМ! 250 МЕТРОВ ОТ ВАС! ☠»
7. **Торнадо** — появляется во время грозы, рвёт блоки и подбрасывает существ.
8. **Слой блок Krita** — ставишь блок и рисуешь на нём зло (правый клик переключает рисунки).
9. **Блок браузера (ПК)** — правый клик открывает рабочий встроенный браузер OmegaBrowser 3000.
10. **Злые рыбки** — ударишь рыбу или порыбачишь — за тобой погонятся злые рыбки и будут кусать.
11. **Soundpad-моб** — сам производит рандомные звуки; при убийстве выпадает предмет рандомных звуков.
12. **Самолёт** — предмет, из которого появляется самолёт; садись и лети куда смотришь.
13. Напиши **«роблокс»** в чате — тебе расскажут твою шуточную историю браузера.
14. **mart** из Roblox-игры nullscape — бродит по ночам и шепчет жуткие фразы.
15. **NULL** — страшный супер-дупер монстр (500 HP), наводит тьму и смотрит из темноты.
16. **Носки фембойчика** — дают **+1000 HP** и **+100 силы**.

## Сборка

```
gradle build
```

Jar появится в `build/libs/`. Сборка также автоматически запускается через GitHub Actions при пуше в ветку, а готовый `.jar` выкладывается в Releases.
