# Super Duper Scary Omega Horror

Экспериментальный мод для **Minecraft Java 1.20.1 / Forge 47.2.0**. Это ранний прототип, а не готовая реализация всех задумок.

## Что уже есть

- При размещении пяти кнопок в радиусе четырёх блоков появляется Великая злая кнопка (пока выглядит как зомби). Она расставляет дубовые кнопки; после смерти выпадает ровно 240 кнопок. Пока поблизости уже есть такой моб, ещё один не появляется.
- Иногда рядом с игроками появляются Давид, NULL, Soundpad и Mart: пока это именованные зомби-заглушки, а не полноценные модели. Давид убирает оказавшихся рядом коров. Soundpad издаёт пещерные звуки и оставляет предмет, который воспроизводит звук по правому клику.
- Если ударить рыбку, рыбки поблизости преследуют и кусают игрока. Рыбалка пока не запускает эту реакцию.
- Иногда появляется явно обозначенное как шутка сообщение о насосе Василии. При слове «роблокс» или «roblox» в чате игроку показывается **вымышленная** история браузера. Мод не читает реальную историю и не взламывает компьютер.
- Носки в инвентаре дают повышение здоровья и силу; для полного заполнения дополнительного здоровья требуется лечение. В творческом инвентаре есть блок Krita, пока без рисования.

## Ещё не реализовано

Планета Iris, жидкое молоко и награда за купание, кража молока Давидом, торнадо, рисование на блоке Krita, рабочий браузер, самолёт, реакция на рыбалку и полноценные уникальные модели и механики монстров. Эти функции не следует считать готовыми.

## Сборка

Установите JDK 17 и Gradle 8.1.1, затем выполните `gradle build`. Готовый JAR будет в `build/libs/`; установите его в папку `mods` клиента и сервера Forge 1.20.1. Для проверки в среде разработки используйте `gradle runClient`. Для первой сборки нужен доступ к репозиториям Forge и Gradle. Gradle Wrapper в проект пока не включён.

Сборка в текущей среде не проверена: здесь отсутствует JDK и недоступен репозиторий Forge.
